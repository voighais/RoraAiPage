Full command reference

All commands go in the you › prompt and start with /. Plain text without a slash goes to the model as a request.

Chats

  • /new — start a new chat, current one is saved to ~/.rora/sessions/
  • /sessions — list all saved chats with numbers and dates
  • /switch <n> — switch to chat number n
  • /delete <n> — delete chat n
  • /purge — delete ALL chats (asks for confirmation)
  • /rename <title> — rename current chat
  • /reset — clear current chat history

Models & config

  • /models — list all .gguf in ~/models, current is marked
  • /model — show current model + list
  • /model <n> — switch to model n without restart
  • /reload-prompt — reload ~/.rora/system_prompt.txt
  • /config — show paths and current config values

Themes

  • /theme — list all presets with color swatches
  • /theme <name> — switch theme (basic, halloween, dracula, matrix, etc.)
  • /theme bg <color> — set terminal background (#hex, R,G,B, or none)
  • /theme edit <key> <value> — change a single color
  • /theme reset — drop custom overrides
  • /theme save <name> — save current as new preset

Files & shell

  • /cd <path> — change working directory
  • /ls [path] — list files in a folder
  • /open <path> — open file/folder in file manager
  • /sh <cmd> — run a shell command manually (through denylist)

Misc

  • /help — help screen
  • /exit — save and quit (same: /quit, :q)

Tools the model calls automatically

The model can call these without a slash command — just describe the task:

  • list_dir — list files in a folder
  • read_file — read a file
  • write_file — create/overwrite a file
  • edit_file — replace a substring in a file
  • append_file — append to end
  • mkdir — create a folder
  • delete_path — delete file/folder
  • move_path — move/rename
  • copy_path — copy
  • find_files — glob search
  • grep — regex search inside files
  • open_path — open in file manager
  • run_command — run shell command (optionally in a folder)
  • open_browser — open browser with URL
  • get_time / get_date — time and date
  • process_list — list processes
  • process_kill — kill process by name
  • disk_usage — disk space
  • timer — timer with notification
  • notify — popup notification
